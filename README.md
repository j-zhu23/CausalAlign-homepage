# CausalAlign project page

Static, buildless project page for **CausalAlign: Causal Alignment of Video Generation Models for Consistent Ego-Motion**. The layout follows the centered hero, blue resource buttons, demo chapters, and rounded light-grey research panels of the [D4RT project page](https://d4rt-paper.github.io/); its text, figures, tables, and video are CausalAlign material.

Page order: title and authors → demo → three-stage method → quantitative results (Figure 3, Tables 1–2) → qualitative results (Figures 4 and 6).

## Preview

From the repository root:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/`. No build step or package installation is required to serve the committed page.

## Source material

The assets are generated by `scripts/prepare_assets.py` from the paper workspace. The committed PDF is the updated `D:/360Downloads/CausalAlign_open (1).pdf`; the figure assets come from the paper's `Figure/` directory and the three-stage method slide layers. The embedded demo is the latest 93-second render. To regenerate on the original workspace:

```sh
python scripts/prepare_assets.py --workspace .. --paper-pdf "D:/360Downloads/CausalAlign_open (1).pdf"
```

This optional asset-building script requires PyMuPDF, Pillow, and OpenCV. The site itself has no runtime dependency on them.
